# 对话定位与匿名隧道恢复（2026-11-06）

2026-11-10状态：对话定位栏继续适用；下文独立匿名隧道、固定隧道和中继的恢复策略是历史实现，已由[统一账号与工作区契约](account-unified-experience.md)退役，不再是当前源码的连接方式或恢复承诺。旧公开安装包仍可能包含历史界面。

## 对话记录定位栏

依据用户提供的桌面截图，在会话正文左侧增加细刻度定位栏。一个用户消息对应一个刻度；悬停或键盘聚焦显示该问题及所属回合的最终回答摘要，点击刻度或预览中的「跳转到此处」直接定位。工具执行过程保持原先的折叠状态。当前阅读位置显示较长的深色刻度；手动阅读后沿用原会话的停止跟随行为，不因新增定位栏而自动回到底部。

定位栏直接使用会话缓存里已加载的消息，不建立第二条连接或重复读取历史。记录多时刻度区自身可滚动，并保持当前刻度可见；顶部的向上按钮使用现有分页加载更早记录，保留正文阅读锚点并为新消息增加刻度。尚未加载的历史不会伪造刻度。切换会话会清空预览和定位高亮，随后使用目标会话自己的缓存。

桌面侧栏宽 28px，移动端 22px；预览最大宽 360px，受移动端视口约束。支持上下方向键、Home/End 选择刻度，Enter/空格定位；Escape、点击外部和移出定位栏关闭预览。预览与刻度之间保留可穿过的鼠标热区。启用减少动态效果时取消定位动画。只读纯文本摘要，不执行历史内容中的 HTML。

## 匿名隧道恢复策略

将「用户要求开启」与进程/网络瞬时状态分开。当前管理器内保存原启动计划、验证身份与代际号，不将凭据写入新增配置或日志。

| 触发条件 | 行为 | 地址处理 |
| --- | --- | --- |
| 远程断网、TLS 暂未就绪、本地探测超时 | 保留原进程，每次失败后约 5 秒再做认证健康检查 | 保留上次验证地址，标记恢复中 |
| 已运行健康 | 每 15 秒检查 HTTPS 和服务身份 | 沿用原地址 |
| cloudflared 退出或无法启动 | 2、4、8、16、32、60 秒退避，持续重试 | 新地址通过验证后才替换并提示变化 |
| 120 秒仍无任何申请地址 | 停止未完成申请的进程，按退避重试 | 不宣称存在可用地址 |
| 本地访问密钥失效或本机/远端身份不匹配 | 停止该连接与自动恢复 | 清除连接入口，等待用户核对后开启 |
| 手动关闭连接/服务或退出应用 | 取消重试、验证，停止自有连接进程 | 不在后台重新开启 |

已经取得地址的进程不会因为连接恢复超过 120 秒被强制关闭。迟到的旧进程输出和异步验证通过代际号丢弃。进程稳定健康 5 分钟后清除连续崩溃退避计数。新进程尚未通过验证时仍只显示旧地址，禁用配对；现有配对弹窗在连接失效或换址时关闭。固定隧道与中继的启停互相独立，本次自动重试只应用于匿名隧道。

官方依据（只读核对，2026-11-06）：

- [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)：临时 URL 在停止 cloudflared 后失效。
- [cloudflared quick_tunnel.go](https://github.com/cloudflare/cloudflared/blob/master/cmd/cloudflared/tunnel/quick_tunnel.go)：每次 RunQuickTunnel 调用临时隧道申请 API，获得 hostname 和凭据后进入 tunnel supervisor；没有受支持的 Quick Tunnel 旧地址恢复参数。
- [cloudflared supervisor.go](https://github.com/cloudflare/cloudflared/blob/master/supervisor/supervisor.go) 与 [tunnel.go](https://github.com/cloudflare/cloudflared/blob/master/supervisor/tunnel.go)：存活进程的重试与连接回退复用已有 TunnelProperties，支持优先保留进程的恢复策略。

边界：不承诺进程重建或 Cloudflare 回收后保留同一匿名地址；长期固定地址使用已提供的固定域名隧道。没有通过修改第三方应用、进程注入或保存临时私有凭据来假装固定匿名地址。

## 验证范围

Rust 隔离测试启动临时连接器子进程和回环 HTTP 身份服务，覆盖临时断线保留 PID/地址、真实子进程退出后的退避重启、新地址验证与旧代际丢弃、周期性健康检测、启动失败、关闭取消、远程身份不符和本地 HTTP 401 终止重试。不会停止真实网络或修改用户运行中的隧道。

浏览器测试使用隔离 API/IPC，覆盖恢复中开关可关闭、旧地址与倒计时显示、新地址提示、现有 cloudflared 安装流程，以及桌面/移动的预览、点击定位、当前刻度同步、键盘操作、外部关闭、会话切换和历史分页的阅读锚点。真实公网断网/网络切换和休眠唤醒不以隔离测试冒充实机长期验收。

# 设计稿 v2 独立核验

日期：2026-11-11。核验范围为 v2 的品牌、桌面本地信息聚合及 Web 登录、连接、设备入口。会话内部按用户要求冻结。以下结果仅针对设计文档及合成数据原型，不代表真实账号、连接、安全协议或产品功能验收。

结论：v2 减法目标与冻结范围通过核验，当前没有阻塞设计评审的问题。

- 冻结范围通过：相对 v1 基线，Web `session`、`composer`、`transcript`、`panelView`、`workView`、`send` 六个函数逐字不变；涉及消息、输入、审批、工具面板等区域的44条 CSS 规则逐字不变。新增登录专属布局未作用于已连接会话。
- 品牌通过：两份原型不再包含 Layers 占位；data URI 解码字节与 `web/public/icon.svg` 完全一致。浏览器实测侧栏、桌面更新及托管/登录页面的真实六角标志可加载，使用原型 CSP 允许的图片数据源。
- 桌面就绪页通过：地址、复制、首次进入说明及目录位于本地工作区面板内，地址常显且不在 `details` 内；去掉重复主标题、装饰盒及侧栏远程状态副行。核验发现远程未知页仍使用缓存“已开启”文案，作者已修复并复核：未知时以“状态未知”替代开关，明确恢复前不能更改，不再宣称当前已开启。
- Web 入口通过：默认设备页不显示电脑选择器，内容区不重复顶栏标题；设备空态只保留一个添加电脑主动作。登录与托管页使用单列居中布局，无空侧栏和无效账号菜单，各有一处真实品牌与一个标题。登录演示可返回设备页。
- 连接后侧栏通过：设备入口为透明无框单行，无状态第二行；图标与“新会话”图标横坐标一致，文本左对齐，箭头位于右侧。对话内部未重新设计。
- 关键路径通过：首次身份核对在勾选前禁止确认；换钥显示专门核对标题，可取消；设备状态未知禁止新连接；远程关闭确认可取消。旧版 widgetState 被版本标识隔离，桌面首次仍默认就绪，Web 首次仍默认设备列表。
- 隔离浏览器尺寸检查通过：1440、960、800、390px 的相关页面无整体横向溢出，320px 另作快速检查；未捕获原型 JavaScript 错误。使用标准 visualize 包裹页，左右各16px，因此原型实际宽度为外窗口减32px。仅操作独立 Headless Chrome 的合成原型，没有操作真实用户窗口或账号。
- 当前引用的七张截图均更新为 v2 六角品牌；只调整页面、尺寸与工具面板的展示状态，不重新验证已冻结的聊天深层功能。真实 OAuth、托管页品牌配置、IPC、网络握手、安装更新和完整标签/消息/审批语义仍需正式实施验证。

v1 核验作为历史结论保留：当时已检查默认远程、手动关闭保持、外部服务不停止、设置草稿离开保护、本机授权与 Web 账号独立、断线保留草稿且不自动重发。v1 发现的活动连接未默认折叠和未保存设置缺少离开确认已由作者修复；这些历史结果不代表本轮再次完成真实功能验收。以下截图已由 v2 覆盖，不作为 v1 原始图像证据。

# 统一外壳与视觉

状态：设计讨论稿 v2。适用于桌面控制台及 Web 登录、连接、设备入口；已连接工作区仅调整品牌与设备选择入口，对话内部维持 v1 原型。整体范围见 [README](README.md)。

## 整体结构

```text
┌─────────────────────┬─────────────────────────────────────────────────┐
│ [六角标志] AnyWork   │ 当前页面 / 当前会话                 [局部工具] │
│                     ├─────────────────────────────────────────────────┤
│ 电脑 工作电脑    ▾  │                                                 │
│                     │                                                 │
│ 当前阶段的导航      │                   主内容                        │
│                     │                                                 │
│                     │                                                 │
│                     │                                                 │
│ 设置 / 更新或帮助   │                                                 │
│ [账号与状态      ▾] │                                                 │
└─────────────────────┴─────────────────────────────────────────────────┘
```

单层顶栏表达当前内容；品牌、账号和电脑上下文各有固定位置。文件或终端打开时，内容区内出现工具面板标题，不在整个界面上再叠一层账号栏。Web 不再使用设备页的大站点页眉、工作区账号栏和重复品牌栏三套结构。

v2 中，登录与托管授权页采用单列居中布局，去掉空侧栏和重复的内容顶栏，只保留一处六角品牌、必要标题与授权操作，轻量帮助放在表单下方。设备页由顶栏承担页面标题，内容区不再重复。侧栏选中导航是位置指引，主区不再额外放一个“我的设备”选择框。对话区继续使用已有 v1 结构。

| 主按钮 | 深色底浅色字 | 浅色底深色字 |

系统 UI 字体，中文保留随包 Noto Sans SC 回退。正文 14px，次级 12–13px，内容页标题 22–24px，引导主标题 28–32px。代码/路径按需用等宽字体。按钮高 32–36px，触屏有效点击区至少 44px。常规控件圆角 8px，输入框 10px，对话输入区 18–22px；布局分区用间距和少量分隔线，避免反复套卡片。

所有品牌位置直接使用现有六角形双眼标志 [`web/public/icon.svg`](../../../web/public/icon.svg)，包括侧栏、桌面更新及托管账号页示意。不得用 Layers、终端图标或加边框的图标盒替代。仅按所需尺寸等比显示，不额外描边或套底板；图标源见 [品牌规范](../../brand.md)。Codex 参考用于布局、密度和交互层级，不引入其专属业务或品牌。

## 导航与上下文

| 阶段 | 侧栏顶部 | 中部 | 底部 |
| --- | --- | --- | --- |
| 桌面引导 | 品牌 | 介绍 / 登录 / 准备的阶段指示 | 设置、更新 |
| 桌面就绪 | 六角品牌 | 工作区、远程访问；状态集中在内容区 | 设置、更新、账号 |
| Web 未登录 | 无侧栏；品牌位于居中的登录区 | 登录 / 注册与必要说明 | 表单下方的帮助、语言 |
| Web 已登录未连接 | 六角品牌，无设备选择器 | 我的设备 | 帮助、语言、账号 |
| Web 已连接 | 六角品牌、无框单行电脑入口 | 新会话、搜索、Agent 筛选、按目录分组的会话 | 设置与插件、通知入口、账号 |
| Web 本地 | 品牌、这台电脑 / 本机浏览器 | 同一套实际会话导航 | 设置与插件、本机网页会话菜单 |

Web 只有连接后的侧栏显示电脑切换入口，与导航采用相同水平内边距、16px 图标槽和左对齐文字；名称可截断，箭头固定靠右，完整名称保留在可访问名称中。入口使用透明背景，无常驻边框和独立卡片；悬停、展开和键盘焦点仍有清晰反馈。入口不显示状态第二行；连接状态在现有内容顶栏表达一次。

该入口的菜单提供“我的设备 / 切换电脑”，本机模式按需显示来源。切换设备离开当前连接时说明“断开本页连接，电脑上的任务继续”，不把它描述成停止 Agent。离线与目录未知应阻止打开，在线仍需安全连接就绪。未登录不显示禁用的设备导航和没有意义的账号菜单；登录与注册动作由内容区提供。

## 键盘与弹层

| 输入 | 作用范围 | 行为 |
| --- | --- | --- |
| Tab / Shift+Tab | 页面 | 按视觉顺序移动，焦点清晰可见 |
| Enter / Space | 按钮、展开项 | 触发当前动作；处理中不重复提交 |
| Escape | 最上层菜单或弹窗 | 关闭可取消的顶层；焦点回触发器 |
| Enter | 对话输入框 | 桌面发送；输入法组合不发送 |
| Shift+Enter | 对话输入框 | 换行；手机沿用既有输入规则 |
| 方向键 / Home / End | 子窗口标签与分隔条 | 保留现有标签切换和分屏键盘契约 |

弹层层级：菜单/浮层 → 确认弹窗 → 安装中阻塞状态。确认弹窗限制焦点在内部；取消与 Escape 返回原触发器。停止服务、退出账号、远程关闭有活动连接时先说明影响，默认聚焦取消；没有活动连接的远程关闭可直接执行。安装提交后不得通过 Escape 造成虚假的取消。

## 尺寸

| 宽度 | 布局 |
| --- | --- |
| 1440px 及以上 | 220–240px 侧栏；会话正文最多 768px；工具面板按剩余空间分配 |
| 桌面默认 960×720 | 220px 侧栏，主内容 32px 左右留白；主要动作在首屏可达 |
| 桌面最小 800×620 | 侧栏可减至 200px，留白 24px，设置允许内容纵向滚动 |
| Web 721–1024px | 侧栏可收起；工具面板优先保留内容宽度 |
| Web ≤720px | 导航为抽屉，工具全宽覆盖主内容；关闭返回会话并保留草稿 |
| Web 390px / 原型嵌入窄宽 | 单列重排，长路径换行，操作换行，无整体横向滚动 |

桌面原生最小窗口沿用当前 800×620；390px 是 Web 和原型的适配要求，不表示要改变原生最小尺寸。保留 Web 既有外观偏好。原型跟随宿主明暗模式；正式桌面是否新增深色设置另行决定，不将原型表现当作已实现能力。

Web 还需覆盖 390×480 的矮窗口：设备及账号上下文不能把会话列表压成仅能容纳一行的区域。优先压缩新增导航的留白、合并已有底部品牌与账号位置或采用合理的侧栏滚动分区；设备切换和安全退出仍可达。保留真实触摸的进展、上下边界与禁止页面滚动链行为，不以扩大测试超时替代可用布局。

# 桌面控制台框线稿

状态：设计讨论稿 v2。页面入口为现有 `desktop/ui/src/main.tsx`；布局提案与业务约束分开记录，统一参数见 [shell](shell.md)。v2 将本地地址、说明与操作合并在一个面板内，并减少重复标题和装饰。

## 引导与登录

```text
┌───────────────────┬─────────────────────────────────────────────┐
│ AnyWork           │ 开始使用                                    │
│                   ├─────────────────────────────────────────────┤
│ ● 功能介绍        │ 把这台电脑的工作区                          │
│ ○ 登录账号        │ 带到你的每一台设备                          │
│ ○ 准备工作区      │                                             │
│                   │ 本机运行 Agent，手机和网页继续工作。        │
│                   │                                             │
│                   │ [这台电脑] ─┬─ [本机浏览器]                 │
│                   │             └─ [手机 / 其他网页]            │
│                   │                                             │
│                   │ [开始使用]                                  │
│ 设置 / 更新       │ 登录并准备后默认开启远程，可随时关闭。      │
└───────────────────┴─────────────────────────────────────────────┘

登录内容替换上方主区：
  登录 AnyWork
  在系统浏览器安全完成登录。
  [登录已有账号]  [创建账号]
  等待时：等待浏览器完成登录… [取消登录]
```

每次新 Native 内存会话保留介绍与登录阶段；设置或更新返回后回到原阶段。账号状态未知时展示核验状态，不误认已退出或允许新启动。登录中断可取消后重试；需要重新授权明确引导结束旧授权；平台不支持时说明独立 CLI 入口，不伪造“继续”绕过。

## 服务准备

```text
准备工作区
已登录示例账号

✓ 核验账号
… 准备 / 验证本地服务
  本地就绪后准备远程访问

失败：工作区还没有就绪。
[重试准备] [打开设置]                 [诊断详情 ▸]
```

准备本地服务与开启远程分为两步。远程失败不阻断已就绪的本地工作，也不让整屏一直停在“准备中”。同一登录只自动准备一次；失败后用户显式重试，轮询不反复提交。

## 就绪主屏

```text
┌───────────────────┬─────────────────────────────────────────────┐
│ 六角标志 AnyWork  │ 这台电脑                                    │
│                   ├─────────────────────────────────────────────┤
│                   │ ┌─────────────────────────────────────────┐ │
│ 工作区         ▪  │ │ 本地工作区                    ● 已就绪 │ │
│ 远程访问          │ │                                         │ │
│                   │ │ [打开本地工作区 ↗]                     │ │
│                   │ │                                         │ │
│                   │ │ 本地地址  http://127.0.0.1:端口/ [复制] │ │
│                   │ │ 首次或会话过期时，请用上方按钮进入。   │ │
│                   │ │                                         │ │
│                   │ │ 工作目录   /示例/项目                   │ │
│                   │ └─────────────────────────────────────────┘ │
│ 设置              │                                             │
│ 更新              │ 远程访问       已开启 · 2 个活动连接     ›  │
│ 示例账号       ▾  │                                             │
└───────────────────┴─────────────────────────────────────────────┘
```

顶栏只保留“这台电脑”一次，主内容直接进入本地工作区面板，不重复页面标题、介绍段和装饰电脑图标盒。就绪状态只放在面板标题行。主屏只突出“打开本地工作区”一个主动作。

本地裸地址、复制、首次打开说明和工作目录直接平铺在面板内；不再设置“本地访问地址与说明”折叠，不在面板外另放地址块。工作目录可选择文本，路径过长换行或中间截断并保留完整可访问名称。地址仅来自 snapshot 已保存的合法端口；不显示 ticket/bearer。状态未就绪/未知时复制和打开禁用，不能从设置草稿生成已就绪地址。打开仍使用 `desktop_open` 安全交接。

面板下保留一条可进入远程页的状态摘要；侧栏“远程访问”只是导航，不再同时重复状态和活动数。连接列表、身份和详细诊断仍在远程页按需查看。

本地就绪且远程失败时，远程摘要显示“未能开启 · 重试”，本地主按钮继续可用；本地快照不可用时显示“本机状态暂不可用”，不能沿用绿色就绪指示继续提交。

## 远程访问

```text
远程访问                                      [已开启  开关]
让同一账号的其他设备连接这台电脑。

其他设备的账号入口
<由账号配置提供的 HTTPS 裸地址>              [复制] [打开]

[如何连接其他设备 ▸]
  打开账号入口 → 登录同一账号 → 选择电脑 → 首次核对身份

[已连接设备              2 个活动连接 ▸]
  手机   iPhone / iPad 浏览器       已连接     开始于 10:20
  网页   网页客户端                已连接     开始于 10:32

[本机身份核对 ▸]
  设备身份 / 设备公钥                 [复制设备身份与公钥]
```

列表默认收起；摘要仍可见。未知、零连接、远程关闭三态分别显示，不能用“0”代替读取失败。活动连接取自 gateway 已握手连接，每行代表一个连接，不宣称物理设备去重，不显示推测的设备型号、IP 或访问正文。

远程开关处理中显示“正在开启/关闭”，不接受重复操作。存在连接时关闭先确认：“关闭远程访问？将断开当前 2 个活动连接，本地工作区继续可用。”确认后列表不再保留旧连接。本次登录手动关闭后保持关闭，切页或重新准备不自动重开。默认开启失败只给显式重试；错误码放诊断展开区。

入口地址缺失或无效时显示暂不可用，禁用复制/打开，不硬编码产品域名。身份核对沿用真实 installationId/publicKey 只读字段，不新增没有协议依据的身份码。

## 设置与更新

```text
设置
本地服务
  工作目录       [ /示例/项目                       ] [选择]
  服务数据目录   [ /示例/数据                       ] [选择]
  本机端口       [ 已保存端口                      ]
  [保存本机设置]
  本应用服务运行时不可保存目录和端口。

[服务程序 ▸]  程序路径 / 选择 / 保存
[连接与隐私说明 ▸]

本应用启动的服务                  [停止本地服务]

软件更新
AnyWork · 当前版本（来自更新快照）
更新状态 / 下载进度 / 错误反馈
[检查更新] 或 [更新并重启] [稍后提醒]    [发行说明]
自动检查并后台下载                           [开关]
[更新内容 ▸]
```

设置草稿与已保存快照分离，轮询不覆盖正在编辑的字段。未保存改动离开时给“继续编辑 / 放弃更改”选择。运行中提供锁定原因；只对本应用拥有的服务显示停止，不允许为了修改配置停止外部 CLI 服务。停止前说明将中断本地和远程，Native 仍须检查任务空闲；忙或未知时拒绝，留在当前页展示原因。

更新保留签名核验、下载、稍后提醒和显式安装确认。安装确认说明重启后需要重新介绍/登录；新登录和本地就绪后默认尝试远程一次。任务执行/等待确认或状态未知时不安装。用户返回工作页后不丢失下载进度；安装中禁止新打开工作区或重复安装。

账号菜单包括退出，说明“关闭远程访问，保留已运行的本地工作；再次从桌面打开需重新登录”。不把退出账号、退出本机 Web 和退出桌面混成同一个动作。

## 主要状态与恢复

| 状态 | 用户看见 | 可用恢复动作 |
| --- | --- | --- |
| 登录等待 | 等待系统浏览器，业务导航不出现 | 取消登录 |
| 准备失败 | 简短原因，诊断可展开 | 重试准备、设置 |
| 已核验外部服务 | 已就绪 / 复用已有服务 | 打开；不显示停止外部服务 |
| 远程准备失败 | 本地已就绪，远程错误摘要 | 打开本地、手动重试远程 |
| 手动关闭远程 | 已关闭，活动列表不显示旧连接 | 显式开启 |
| 本机或账号未知 | 状态暂不可用 | 自动恢复只读观察，必要操作禁用 |
| 停止/安装遇到忙或未知 | 任务未空闲或无法确认 | 取消、任务结束后再试 |

## 页面与组件建议

`DesktopShell` → `OnboardingFlow` / `LocalWorkspacePage` / `RemoteAccessPage` / `LocalSettingsPage` / `UpdatePage`，共享 `AccountMenu`、`StatusLine`、`Disclosure` 和 `ConfirmDialog`。IPC、授权 owner 和默认远程消费仍由现有控制器及 Native 持有，不能把换外壳变成重建授权状态。

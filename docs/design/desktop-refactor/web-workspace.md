全局账号与当前电脑移入侧栏后，内容区只有一层顶栏。会话对话标签不可关闭，已打开的文件/变更/目标/终端/子 Agent 仍保留当前会话的标签组；工具按钮用于打开，标签用于切换已打开内容。工具入口按实际支持能力生成，不虚构未实现的音频或模型能力。

## 消息、输入与执行

消息区保留助手正文、用户消息、工具活动及真实错误。已完成工作过程折叠，最终回复常显；活动展开读取实际详情。保留图片预览、文件链接、复制、可用的历史编辑和更多操作，能力不足时不展示假按钮。

输入区保持一个连续控件，附件预览在文本上方，底部为添加、权限、模型/强度和发送/停止。模型、强度和速度从真实会话能力读取，不硬编码“最新”型号。当前会话不支持执行或原 owner 未连接时，保留阅读并解释为什么不能发送。

运行中无草稿显示停止；有补充内容时按现有队列/引导偏好发送，不因重新设计改变投递语义。待发送队列置于输入框上方，目标状态同区展示，编辑/删除保留现有事务及恢复规则。新会话创建时可选 Agent 和工作目录，不能默认为所有可见 Agent 都可执行。

审批固定在输入区上方，明确命令、目录、权限范围及实际可用决定。仅在真实请求和协议允许时显示“允许一次 / 本回合有效 / 本对话 / 类似命令”等选择；不以笼统同意替代。问答同区呈现实际选项和自由输入。多请求、输入法、已有弹层的快捷键保护沿用原实现。

权限范围：仅此请求 / 本回合有效（来自协议）
[拒绝]                               [允许一次] [审批选项 ▾]

## 断线与离开

```text
工作电脑 · 连接已断开
现有消息只读显示；输入草稿保留。
[重新连接] [选择其他电脑]

输入区：连接恢复后才能发送                  [发送禁用]
```

断线不自动重发消息、审批或终端写入。重连成功后恢复读取和状态核对；发送结果未知应显示核对动作，避免用户误以为没有发送而重复执行。恢复之前保留可读消息及文字草稿，不展示“已同步”承诺。

授权过期与一般网络断线分开显示：过期需返回账号或设备连接流程；公钥变化进入身份核对。本机 cookie 失效转到本机入口，提示从桌面重新打开，不强行送到 Web OAuth。

切换电脑与账号时关闭旧 transport，按服务器/账号/设备 scope 隔离草稿、历史和面板；仍未提交的附件跨切换能力以现有规则为准，不承诺自动带到另一台电脑。退出 Web 账号不退出桌面账号，不停止电脑上的 Agent 任务。

## 设置、通知与移动端

设置与插件在左下使用稳定入口，内部保留常规、外观、Agent 与连接以及实际插件管理；不把 Native 路径与桌面服务控制放进 Web 设置。外观选项保留浅色、深色、跟随系统及已有偏好，默认中性 Codex 风格。

通知中心在首页与会话均能找到，显示现有前台事件和浏览器通知能力；不暗示浏览器关闭后仍有原生后台推送。

移动端顶部显示菜单、会话标题和工具入口；设备切换、账号和设置放入同一抽屉。输入字号至少16px并保留底部安全区。设备切换、审批和关闭面板有效目标至少44px。长会话标题截断后可读取全文，长命令/文件路径在详情内换行。

## 组件与验收范围

建议 `WebShell` 内组合 `DeviceSwitcher`、`SessionNavigation`、`WorkspaceHeader`、`WorkspaceHome` / `ConversationSurface`、`ConversationPanel` 与 `AccountMenu`。现有 `Composer`、`RequestCard`、`SessionTabs`、`SplitPane`、`Settings`、`NotificationCenter` 保留业务控制，仅调整容器和视觉。

正式实施需覆盖：从设备进入工作区时外壳不跳变；返回设备关闭原连接；本机与远程账号显示不混淆；搜索/筛选/归档不丢失；会话切换保留各自面板；审批和队列不重复提交；文件操作与历史编辑恢复规则有效；断线时草稿可恢复且不会自动重发。本轮原型使用合成消息，不能替代这些功能验收。

# 会话缓存、子窗口入口与桌面目标暂停

2026-11-06。本轮修正会话切换的缓存与连接生命周期、合并子窗口入口，并补充现有桌面共享协议下的目标暂停操作。

## 会话与连接

`SessionHistoryCache` 按已认证的 `Api` 实例隔离。会话切换只切换快照订阅，不销毁历史、分页、控制事件和连接。当前页面保留全部运行、等待、启动中的会话；另保留最近访问的 24 个后台闲置会话，选中会话和打开的子 Agent 详情不会被淘汰。缓存放在内存，注销、切换服务器或页面刷新后重新读取，不将会话内容写入长期浏览器存储。

新服务端使用一条带 Bearer 认证的 `/api/events` SSE 多路推送。所有会话共享数据库的全局事件序号。初次 `/api/events/poll` 取得水位，再读取各会话历史；水位之后的事件经长连接送达。首次快照和实时消息交错时按序合并，重连保留游标和已加载消息。匿名 Cloudflare 域名继续使用同一游标的 JSON polling。缺少全局接口的旧服务端回退为持久的会话连接；普通网络错误只重试，不永久误判为旧版。

桌面会话的正文以原 owner 的规范历史为准。桌面快照变化会产生 `thread/history/updated`，前端合并短时间内的通知，再更新相应会话；15 秒的兜底读取只用于活动或选中的桌面会话。支持后端的情况下不再每秒重复读取正文。初次控制事件重放只读取权限请求、请求完成及执行状态，避免跳过长连接水位之前已有的审批。迟到的历史、分页和旧账号响应不会覆盖新状态；同步失败保留缓存，手动重试立即重新连接。

子 Agent 详情复用同一缓存和事件连接，关闭再打开无需重读相同正文。查看闲置子会话只读取历史，不因为打开面板启动新引擎。

## 子窗口入口

每个会话拥有自己的子窗口标签组。入口只有一个加号，在当前标题行最右边；打开面板后入口位于面板标题行最右边。新建菜单仅提供文件、变更、目标、终端。Subagents 只通过正文中的成员活动打开，已打开的标签仍可切换。

## 桌面目标控制的原包依据

用户指定 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 只读，SHA-256：

`5ddc4e48259aa6f979e04529b1a5a4ae54b0f5c4ad6db5c6e004924c10916ddb`

本轮 REA 选择 `.vite/build/src-DsLVGakC.js`，保留 Evidence 为 `ev_58164bbc40293268eb8748f4f1894f509409f86582c8bba77dbaedd1579f0e1f`，摘要为 `ev_b492664f8b1b7e8dfef5288de470673eaff0542db789f6e678443a96997c122b`。模块 SHA-256：`28a0918f01c50b0eb17676e894998ad7182f119d978adf0467ccaac3583f259c`。分析为静态、限定模块，语义图达到配置的容量，不能据此断言全部动态入口均不存在。归档内未打包原模块或分析缓存。

定向读取确认：目标编辑和状态修改通过 manager 的原请求客户端发送 `thread/goal/set`；清除使用 `thread/goal/clear`。但该版本的 follower 注册表没有目标设置或清除方法，AnyWork 原适配器的白名单也未实现这些方法，因此出现用户报告的错误。

原宿主另有已注册的 `thread-follower-interrupt-turn`。**省略 expectedTurnId 的版本 3 user-stop 路径，会先通过原请求客户端暂停活动目标，再停止当前执行。带 expectedTurnId 的版本 4 路径会提前进入指定回合停止逻辑，不暂停目标，不能互换。** 本轮将桌面适配器的目标暂停映射到版本 3，固定目标 owner，不创建另一执行引擎，等待原桌面快照确认目标为 paused 后才返回成功。原宿主报告 goalPauseError 时原样报告失败，送达不明时不自动重放；已暂停目标重复操作不再发送命令。

这个适配具有明确的语义限制：它会暂停目标并停止当前执行，**不等价于桌面内部只修改目标状态、让当前回合继续的目标编辑 API**。原 stdio 宿主的恢复、编辑、删除目标仍未找到可用的 follower 入口，返回明确说明并保留原状态；应在桌面中操作，或使用既有共享引擎启动方案。直接使用原生共享引擎的会话仍走已有的 thread/goal/set、thread/goal/clear，未被这个桌面适配分支限制。

对现有桌面会话的只读检查显示：独立共享 daemon 返回 notLoaded，不能将它当作原 stdio 引擎来写目标；本轮没有在原会话发送测试消息、暂停真实目标、重启或修改原 Codex。

## 验证范围

缓存测试覆盖切换不重读、后台更新去重、快照与事件交错、重连游标、网络故障、历史分页及回退、手动重试、旧版回退、StrictMode 生命周期、认证隔离、LRU、已有权限请求恢复和子会话缓存。

桌面宿主 HTTP fixture 覆盖原 owner、原 thread/turn、权限请求、目标暂停成功及失败、状态确认、全局事件水位与 SSE 重放、鉴权。该 fixture 不冒充对原桌面真实目标的动态暂停验收。

浏览器检查使用桌面和 Pixel 7 两种视口，包括单一加号、菜单关闭、每会话标签组、两会话共享 SSE、后台消息、无重复历史请求、子 Agent 导航及实时更新期间保留图片查看器。详细构建和回归结果在 validation-2026-11-06.md 的本轮补充中记录。

# 手机客户端布局

沿用六角标志、系统字体和黑白中性色：背景 #FFFFFF、正文 #171717、次级 #737373、分隔线 #E5E5E5、在线 #228554、错误 #B42318。正文和输入16px，标题22px，注释13px；16px页面边距、至少48dp触控区域。列表分隔表达设备/会话关系，不复制桌面侧栏缩小显示。

```text
首启 → 应用内登录 → 我的设备 → 公钥核验 → 会话工作区
                     │                     │
                     账号/外观           对话/文件/终端

┌───────────────────────────┐
│ ◇ AnyWork             账号│
│ 我的设备                  │
│ [电脑名称]          [连接]│
│ 在线 · macOS              │
│───────────────────────────│
│ 在电脑上打开 AnyWork      │
│ 登录相同账号并启用远程访问│
└───────────────────────────┘

┌───────────────────────────┐
│ < 会话列表    会话标题  ⋯│
│ 电脑 / 工作目录           │
│ 对话       文件       终端│
│───────────────────────────│
│ 消息与工具活动            │
│ [待回应 · 查看]           │
│ ┌───────────────────────┐ │
│ │ 输入消息…             │ │
│ │ ＋ 模型与权限     发送│ │
│ └───────────────────────┘ │
└───────────────────────────┘
```

首启介绍手机继续电脑工作、账号与加密连接，并提供登录/注册和添加电脑说明。进入授权前提示固定登录站点，官方 SDK 的独立登录窗口通过系统返回取消；不依赖其未提供的来源顶栏。取消回入口，失败可重试。设备空态、离线、目录读取失败和需登录各有下一步；核验页显示完整公钥，变化时比较旧/新值。

完整会话保留现有 App 的能力/控制器，以移动导航及样式适配，不复制整份 App。窄屏采用全屏页面和可收起会话列表，更多动作进入菜单。键盘出现时保留输入和发送，终端快捷键不被遮挡，字体放大和横屏不横向溢出。

随包 `mobile.html` 必须加载共享 App 基础样式，包括文件名为 `desktop.css` 的导航、会话行、Agent 图片尺寸与主题选择规则；手机样式在其后覆盖。不能仅用设备页样式替代连接后的完整 App 样式。新会话和搜索保持横排，Agent 图标按设计尺寸显示且只显示当前主题版本，单行会话按后续手测修订保持48–56px，导航与筛选/添加触控区域至少48px。以上规则以手机生产入口的已连接界面回归，不用普通网页入口代替。

2026-11-16 手机手测补充：列表顶部新会话、搜索、Agent 筛选和会话标题按内容紧凑排列，不按剩余高度拉伸或均分空白。相邻单行会话采用48–56px行高，替代此前64px最低值；短列表空余空间留在列表末尾。减少控件间叠加的 padding/margin，不通过缩小根字号掩盖间距。发送/停止控件具有至少48×48px实际触控范围，宽高相等、圆形且不被 flex 压缩；窄屏、长模型名、上传附件及 IME 下保持可见可点。修改只作用 Mobile，保留桌面布局与已有短横屏触摸滚动。

发送区保留草稿、上传中、提交、已接收、执行、排队、停止请求、结果未知和断线语义。结果未知提供查询/核对路径，不自动重发。账号/设备切换隔离草稿及异步结果；审批返回只收起，编辑冲突保留内容。账号页展示真实名称、语言/外观、可信设备及退出；只显示实际实现的原生能力。

原生 inset/IME 为唯一安全区来源；返回键先关闭键盘/浮层，再退子页面/列表，根页交系统。文件明确保存至电脑、保存至手机和分享。PDF不能预览时有实际可用的保存/外部打开入口。全屏/浮层保留可访问名称、焦点、关闭按钮和48dp操作区域。

较矮横屏也须保持核心操作可触达：640×360、IME占180px时，输入和发送不能落在裁剪区域；无IME时终端全部快捷键可通过布局或滚动到达，Ctrl+C不能被底部裁掉。压缩次要标题或使工具区域可滚动时，仍保留可访问名称和实际命中区域，不隐藏键盘来伪造通过。

2026-11-16 文件侧栏与菜单手测补充：手机文件页使用以下顺序。文件树从左向右表达层级，展开箭头、图标、名称保持同一行左对齐；名称截断而不挤压图标。筛选和目录位于预览上方，目录有独立滚动区域；已选文件的预览获得剩余空间。目录与预览间用水平分隔，不沿用桌面的左边框。会话列表沿用上文紧凑布局，不另建导航体系。

```text
标题 / 返回 / 通知 / 会话操作
对话       文件       终端    更多
文件工具栏 / 路径
筛选文件…
▸ 📁 目录名称                 ← 左对齐、≥48px
  📄 文件名称                 ← 层级缩进
────────────────────────────
文件预览 / 未选文件提示        ← 剩余空间
```

“更多会话工具”和手机设备操作菜单属于浮动菜单，接入已有统一菜单生命周期：点击外部、Escape、选择菜单动作、切换所在页面后关闭；内部空白不提前关闭，动作只执行一次，重开可用。同一时刻仅打开一个浮动菜单。活动、目标或目录的普通 details 展开不因此折叠。外部关闭不阻止被点击页面原有动作。短横屏、IME和长路径继续满足上述可触达约束。

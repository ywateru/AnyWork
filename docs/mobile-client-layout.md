# 手机客户端布局

沿用六角标志、系统字体和黑白中性色：背景 #FFFFFF、正文 #171717、次级 #737373、分隔线 #E5E5E5、在线 #228554、错误 #B42318。正文和输入16px，标题22px，注释13px；16px页面边距、至少48dp触控区域。列表分隔表达设备/会话关系，不复制桌面侧栏缩小显示。

```text
首启 → 应用内登录 → 我的设备 → 公钥核验 → 会话工作区
                     │                     │
                     账号/外观           对话/文件/终端

┌───────────────────────────┐
│ ◇ AnyWork             账号│
│ 我的设备                  │
│ [电脑名称]          [连接]│
│ 在线 · macOS              │
│───────────────────────────│
│ 在电脑上打开 AnyWork      │
│ 登录相同账号并启用远程访问│
└───────────────────────────┘

┌───────────────────────────┐
│ < 会话列表    会话标题  ⋯│
│ 电脑 / 工作目录           │
│ 对话       文件       终端│
│───────────────────────────│
│ 消息与工具活动            │
│ [待回应 · 查看]           │
│ ┌───────────────────────┐ │
│ │ 输入消息…             │ │
│ │ ＋ 模型与权限     发送│ │
│ └───────────────────────┘ │
└───────────────────────────┘
```

首启介绍手机继续电脑工作、账号与加密连接，并提供登录/注册和添加电脑说明。登录页有原生关闭和来源提示，取消回入口，失败可重试。设备空态、离线、目录读取失败和需登录各有下一步；核验页显示完整公钥，变化时比较旧/新值。

完整会话保留现有 App 的能力/控制器，以移动导航及样式适配，不复制整份 App。窄屏采用全屏页面和可收起会话列表，更多动作进入菜单。键盘出现时保留输入和发送，终端快捷键不被遮挡，字体放大和横屏不横向溢出。

发送区保留草稿、上传中、提交、已接收、执行、排队、停止请求、结果未知和断线语义。结果未知提供查询/核对路径，不自动重发。账号/设备切换隔离草稿及异步结果；审批返回只收起，编辑冲突保留内容。账号页展示真实名称、语言/外观、可信设备及退出；只显示实际实现的原生能力。

原生 inset/IME 为唯一安全区来源；返回键先关闭键盘/浮层，再退子页面/列表，根页交系统。文件明确保存至电脑、保存至手机和分享。PDF不能预览时有实际可用的保存/外部打开入口。全屏/浮层保留可访问名称、焦点、关闭按钮和48dp操作区域。

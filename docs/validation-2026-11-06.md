## 原包证据与实现

REA 对用户指定桌面应用做只读静态分析，未修改或重启原应用。当前 ASAR SHA-256 为 `5ddc4e48259aa6f979e04529b1a5a4ae54b0f5c4ad6db5c6e004924c10916ddb`，版本为 `26.1013.40934`；它与较早的参考契约所用原包不同。详细模块、Evidence ID、选择范围和未知项分别保存在 [子 Agent 契约](anywork-subagents-contract.md) 与 [工具活动契约](anywork-tool-activity-contract.md)。

- 工具活动采用平面摘要与按需展开；连续完成项合并，正文、失败和执行中项保持顺序。MCP 输出区分内容块、结构化结果和错误，原始输出单独展开。
- 子 Agent 活动使用稳定的原包头像；调用详情显示真实成员、状态和指令，wait 轮询不刷正文。普通 create_thread 不混入 Subagents。
- Subagents 按 Active / Done 分组、按最近活动排序，默认分别显示 4 / 10 条；展示等待、实时运行时长与完成时间。
- 点击成员在同一右侧面板显示详情，保留父会话选中状态和草稿。只有明确可互动的成员展示通用 Composer 与可操作请求，输入和审批绑定真实子会话 ID。未知成员默认只读，不启动执行引擎。
- 子会话图片查看器跨历史刷新保留；文档标签归父会话所有，文件读取使用来源子会话的 ID 和 cwd。

这些是当前协议下的重构结果，不是原应用运行态逐像素一致证明。部分 provider 定制输出、MCP App/widget、原 raw output 模态框、动画与全部滚动时序仍有差异；语音听写与朗读沿用用户确认的暂缓范围。

## 桌面匿名隧道检查与安装流程补充

- 当前桌面包和系统中均存在可执行的 cloudflared，本机的开启问题不能只归因为缺少程序。发现桌面管理器保存的数据目录与当前 3210 服务实际数据目录不一致，两个目录的密钥不匹配；已仅修正本机管理器的数据目录，使用保存配置读取的密钥访问实际服务返回 HTTP 200，未更换服务密钥。
- 默认 QUIC 的隔离真实测试曾通过，也复现过远程 TLS handshake eof 和 HTTP 530。远程检查新增默认连接失败时的直连重试，保留 TLS 证书验证、Bearer 认证和服务身份匹配；新地址验证最多重试 30 次，整体启动超时 120 秒。匿名隧道改用 TCP HTTP/2 后，两轮对照分别在 9.21 秒和 8.81 秒通过；最终代码无需环境变量的完整链路验证在 8.66 秒通过。不能据此保证所有外网环境都可用。
- 新增本地 Tauri cloudflared 检查与安装命令，前端开启匿名/固定隧道前检查程序，缺少程序或配置路径失效时弹出安装对话框。下载适合当前系统架构的官方发布，验证 GitHub 发布的 SHA-256 和文件大小，解压指定成员并验证运行后原子安装到用户目录，保存程序位置并继续开启原连接。取消和失败不会发送启动命令；失败可以重试；安装期间其他远程连接保持独立。
- 桌面 Rust 单元及管理器 fixture：17 passed，3 ignored。忽略项中的官方真实下载安装、真实匿名隧道链路均已分别显式运行通过；本轮未重跑真实 Server 启停用例。
- 官方真实下载测试通过，覆盖下载、校验、解压、运行和重用已安装程序。下载使用临时目录，不替换用户系统程序。

# 工作目录和 Codex 会话发现

服务通过当前系统用户的 Codex app-server 同步会话索引，与 AnyWork 自身的会话合并展示。`--codex-scope workspace`（默认）限制到配置工作区，`--codex-scope all` 列出当前 CODEX_HOME 中所有本机项目，包括其他项目及 cwd 已删除的历史。缺失目录不阻止历史读取，但无法读取已不存在的文件或继续执行。目录名取自会话真实的 `cwd`，不能根据会话标题推断或替换路径。

工作目录从已同步的 Codex 会话及本服务创建的会话的 `cwd` 去重汇总，不扫描文件系统、不预置根目录或空项目。同一完整路径下的多个会话归到同一组，显示名称取真实路径的末级名称。只存在文件夹但没有会话的项目不会出现在侧栏；可在新建会话时填写真实工作路径，创建后自动出现。归档视图仅显示含归档会话的目录。workspace 范围下，符号链接解析后超出配置根目录的会话不会公开；all 范围下仍保持每条会话自身的文件边界。

## 同步与历史

`thread/list` 分别遍历未归档和归档分页，明确列举来源并传入 `modelProviders: []`。其默认来源和默认 provider 过滤可能导致遗漏，不能依赖默认参数。按真实 `thread_id` 与本服务会话去重，导入快照以事务替换，完整同步失败时保留上次索引并返回 `discovery_error`，缓存有效期为 2 秒。

会话标题优先使用 `thread.name`，其次使用原始预览。辅助会话单独分组，Codex 内部自动审查记录不属于用户对话，不展示。归档在独立入口访问。列表只包含当前主机、当前 CODEX_HOME 且符合选定发现范围的会话；其他电脑上的项目需要在对应主机部署或后续接入 Runner。

点击导入会话优先通过 `thread/items/list` 倒序读取最近条目，上滑使用不透明游标加载更早内容；旧版逐级回退 `thread/turns/list` 与 `thread/read(includeTurns: true)`。大型工具结果展开时再读取。客户端每 5 秒仅刷新最新页；读取不调用 `thread/resume`，不向原会话发送消息，也不据单独进程的 `notLoaded` 猜测桌面运行状态。

普通会话现在直接连接原来的 Codex 共享执行进程：选择会话后订阅，空闲时原地续聊、执行中补充指令或停止，并可回答该连接收到的审批/问答。保持原始 thread ID，不再要求创建分支。`thread/resume` 仅传 threadId/excludeTurns，不覆盖模型、权限或审批设置。显式 fork API 保留供其他客户端选择使用。

## 样式和验收

侧栏参考 Codex 的紧凑文件夹分组、缩进标题、浅灰选中行与主机标识，支持浅色/深色和移动抽屉。初始显示每个目录最近五条主会话，“展开显示”访问其余；搜索覆盖所有目录与会话标题，并自动显示匹配结果。

新增 `scripts/discovery-test.py` 覆盖多页索引、归档、辅助会话、越界排除、无会话目录排除、同目录多会话、嵌套目录汇总、历史分页、原会话写保护及分支续聊；浏览器测试覆盖展开、搜索和按目录新建。桌面与手机尺寸的自动化验证使用隔离测试会话，不依赖个人任务或截图。手机浏览器验收不等于安卓真机验收。

参考：[OpenAI 官方 Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)，并用本机 Codex CLI 0.163.0 实际验证协议。

## 普通会话的运行状态

新增本机桌面共享服务只读 observer，优先从原执行进程查询索引、运行状态及最近内容，连接不可用时回退独立查询进程的持久化历史。active/idle/等待回应会在列表与会话页中显示；notLoaded 维持“运行状态未知”。外部会话在本服务重启时不再被写入虚假的任务中断事件。最近内容仍按周期查询快照，共享控制连接接收审批与生命周期通知。未注册控制入口的独立 CLI 进程不能被凭空连接；冷恢复前检查 writer lock，有其他进程占用时明确拒绝，不另起执行进程。详见 [实现对比、验证与限制](session-sync-research.md)。

## 历史可读与控制可用性

持久化索引和共享 daemon 现在独立分页并合并，避免共享索引遮蔽独立进程的历史。持久化源暂时失败时保留旧历史。GET models/composer 不再为外部会话自动恢复执行；连接不可用时返回历史观察状态，页面继续加载消息。connect 的 connected/mode/reason 字段与详细接入方案见 [同步调研](session-sync-research.md)。

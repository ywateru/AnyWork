## Web状态与交互

- 存储键为 `anywork.conversation-panels-v1`；内部键为JSON编码的`[serverUrl,sessionId]`。旧 `ra.open-tabs-v1` 不参与恢复，不把旧会话标签转换成子窗口。
- 对话始终属于当前会话，显示会话标题；每个文件路径对应一个文档标签，重复打开会激活并更新行定位。变更、目标和终端是同会话工具标签。
- 点击加号选择子窗口，只打开当前会话的已有功能；新建会话位于侧栏或会话操作菜单。
- 切换侧栏会话立即读取该会话的标签组与选中项；刷新恢复文件目标与视图。草稿继续按服务器及会话隔离，不随子窗口切换丢失。
- 关闭未选中标签保持当前视图；关闭选中标签选择相邻标签，没有子窗口时回到对话。对话标签不提供关闭。关闭审阅标签或离开审阅视图时移除专用review路由，避免刷新又自动打开。
- 方向键、Home/End用于标签导航；Delete关闭当前子窗口并恢复相邻标签焦点。菜单Escape恢复触发器焦点。窄屏标签横向滚动，不扩展页面宽度。
- 分屏宽度也按服务器和会话隔离。桌面同时展示聊天与面板；手机打开面板后保留顶部标签，正文覆盖，聊天组件继续挂载。
- 目标保存锁在同会话目标条与目标编辑器之间共享，关闭标签后直到保存结束才释放；锁按服务器与会话隔离，其他会话仍可独立编辑目标。迟到结果继续按原操作和会话身份过滤。
- 标签只保存视图状态，不创建、恢复、停止或归档Agent任务。终端自身的PTY连接仍随终端组件生命周期管理；文件未保存编辑稿不承诺跨标签卸载或刷新保存。

## 浮层审查

| 浮层                             | 处理                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| 侧栏分组/目录/归档               | 选择后关闭，含重复选择当前分组；点击/触摸外部、Escape、焦点移出、切换会话关闭                      |
| 会话操作、工作区工具、子窗口加号 | 同上；原生details菜单互斥，Escape与方向键焦点管理                                                  |
| 文件选项                         | 刷新、复制路径、显示/隐藏文件树后关闭，补齐外部点击及Escape                                        |
| 排队消息更多                     | 接入原生菜单外部关闭与互斥；保留原有定位和方向键逻辑，避免双重处理                                 |
| 输入栏添加                       | 保留上传、远程文件、目标及计划动作的关闭规则；补齐焦点移出关闭                                     |
| 模型/思考强度/速度               | 保留portal、速度子菜单、滑杆及保存流程；补齐焦点移出，内部交互不关闭父层                           |
| 回复评价/更多                    | 保留选择、外部点击、Escape、Tab、反馈对话框，补齐焦点移出关闭                                      |
| 审批选项                         | 保留专用请求与scope动作，补齐焦点移出；全局审批快捷键识别所有标记的浮层，避免菜单操作触发批准/拒绝 |
| 审阅来源/提交/选项               | 保留子菜单返回、悬停及portal提示，补齐焦点移出                                                     |
| 链接动作/编辑浮层                | 已有外部点击、焦点移出及两阶段Escape，保持文档编辑与取消语义                                       |

只给菜单details增加`data-floating-menu`，不修改活动记录、消息过程及请求原始数据等信息披露区。图片查看器、目标编辑和反馈表单仍使用各自的对话框逻辑。

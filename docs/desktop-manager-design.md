# AnyWork Rust 桌面设计

2026-11-06：根据新版 UI 讨论稿重构桌面管理程序。当前 Agent 仅支持 Codex；桌面管理程序继续使用 Rust + Tauri 2，服务端、Web 会话和 Android 协议保持兼容。

## 讨论稿要求与设计约定

- 本机 Agent 只显示 Codex 图标与名称，点击进入配置，工作目录保留在悬停提示中。
- 总览呈现 Codex → AnyWork → 三路远程连接。移除 AnyWork 下方的管理归属、箭头和局域网卡片；局域网地址保留在本地服务详情中。
- Cloudflare 匿名隧道、Cloudflare 固定域名、WireGuard + TLS 中继各为独立卡片与开关；去掉共同的外框、外网通道标题、启用计数和整组折叠入口。
- 启动/停止按钮位于 AnyWork 节点内部。支持本机控制且已认证的新版 CLI 服务也可显式停止；旧版服务禁用停止按钮并提示升级。
- 点击连接卡片展开锚定的详情浮层，包括地址、复制、打开网页、生成 Android 配对二维码、查看配置及仅关闭该路连接。配置不足时开启开关会先展开对应配置，不提前发送启动命令。
- 浮层有明确边框，支持外部点击、Escape、再次点击触发器、关闭按钮和切换页面关闭。Escape 和关闭按钮将焦点放回触发器。浮层保持在视口内，长表单在浮层内滚动。
- 保留 cloudflared 检测/下载安装、自动恢复与地址变化提示、密钥管理、在线设备和签名自动更新流程。
- 根据后续评审，移除总览底部的分隔线、本地文件提示和“打开工作台”按钮；工作台入口保留在本地服务详情中。
- 本地服务状态、`127.0.0.1:端口` 和服务设置入口直接整合到 AnyWork 节点。Codex 节点不再展示大卡片、说明文字和工作目录行，点击图标进入配置。
- 连接卡片优先显示实际已知网址（固定域名未启动时可显示已保存的配置地址），省略协议前缀并在空间不足时截断，完整地址保留在悬停提示和详情浮层中。恢复中的匿名隧道保留上次地址与恢复状态。

## 视觉方案

白色 `#FFFFFF` 为页面背景，浅灰 `#FAFAFA` 为导航底色，中性灰 `#F4F4F4` 为轻表面，`#171717` 为文字及主要操作，`#737373` 为说明，`#E7E7E7` 为边界。绿色 `#208454` 仅表示连接成功，错误使用红色。采用新的黑色产品 SVG；不使用蓝色品牌色或装饰渐变。

字体使用系统 UI 字体及随包分发的 Noto Sans SC（OFL）作为中文回退。正文 14–15px、说明 12–13px、页面标题 24–26px。默认窗口 960×720，最小 800×620；不进行全局缩放。Web 新用户默认白底黑白主题，保留已有用户明确选择的主题。

节点按真实尺寸测量并绘制连线，窗口变化、换行和状态变化时重新定位。Codex 图标与 AnyWork 图标对齐，AnyWork 作为宿主节点居中。浮层使用阴影表达层级，连接卡片采用轻边框。评审方案时去掉了讨论稿中的蓝色发光背景、共同外网容器及多 Agent 占位，以符合黑白品牌与当前能力；保留三路连接作为并行分支，而非互斥模式。

960px 默认窗口与 800px 最小窗口保持三列关系图；窄屏改为纵向结构。欢迎页、设备页、设置、更新、安装与配对弹窗共用同一黑白配色，保留键盘焦点及减少动画设置。

## 实现边界

`crates/desktop` 是 Rust 管理核心和 Tauri IPC 边界，`desktop/ui` 是独立 React 界面。Web 会话客户端继续位于 `web`。Tauri 在构建时嵌入管理界面，窗口加载本地资源；Rust commands 提供指定动作、原生选取器、剪贴板和已验证地址的打开操作。管理界面没有通用 shell/fs 插件。

配置采用兼容旧版的 camelCase JSON，按系统应用数据目录存放；旧版单选隧道配置不自动开启任一路由。连接器凭据由系统 keyring 保存，访问密钥文件私有原子写入。每一路连接独立持有 Child、状态、验证任务和取消信号。只有系统 TLS 与已认证 AnyWork 服务身份都验证通过，才公布远程地址。

外部 CLI 服务通过认证连接；仅用户显式点击停止按钮时，管理器才调用兼容服务的本机停止入口。入口拒绝未认证、非本机、经代理转发和浏览器跨源请求，服务有自有任务执行或等待确认时拒绝停止。关闭应用先停止并回收自己持有的路由和服务，再退出，保留独立 CLI 服务。窗口关闭、系统退出和 SIGTERM 都走同一关闭路径。旧 Swift 窗口与 eframe 原型已从交付源码移除。

## 本轮验证

2026-11-06：桌面管理界面生产构建通过；`desktop-overview.spec.ts` 与 `desktop-tunnel.spec.ts` 在 Desktop Chrome 和 Android 触控模拟中共 46 项通过。覆盖 1440×1000、960×720、800×620、390×844 布局，白色默认背景、实际节点连线、地址显示与截断、独立开关、缺失配置、工作目录保存、错误反馈、配对以及浮层关闭/焦点返回。连接详情根据触发器上方和下方空间限制高度并内部滚动，窄屏下仍可再次点击触发器和开关。

本机服务控制另外通过隔离 HTTP 集成测试和 Rust 测试验证，涵盖认证、转发限制、忙碌拒绝、停止确认、重启后数据与密钥保留，以及退出管理器不停止独立服务。

Web 外观集成检查在两种浏览器模拟中通过：新用户默认浅色，显式的跟随系统、颜色及字体配置仍可保存。Web 单元检查 291 项通过。桌面更新界面的独立 IPC 回归通过，涵盖静默下载、失败处理、延后安装、偏好设置、确认安装与过期版本拒绝。以上连接与更新交互均使用隔离夹具，未启动真实隧道、下载真实更新或操作已有 Codex 会话。

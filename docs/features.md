# 功能对照与验收边界

参照 hapi 的远程编程核心流程；不将下载上游代码等同于完成所有上游能力迁移。Agent、连接拓扑、平台和实际验收状态以[当前支持矩阵](support-matrix.md)为准；下表记录功能实现边界，不能将“已实现”视为所有原生版本/平台均已实机验收。

| 功能 | 当前实现边界（版本/验收见支持矩阵） |
| --- | --- |
| Rust 服务端、Agent 插件接口 | 已实现 |
| Codex 真实适配 | 已实现，使用官方 app-server；本机真实会话/模型列表/回答联调通过 |
| DeepSeek Harness | 已接入受支持的共享 gateway 与持久历史；版本、功能和实际 upstream 验收见支持矩阵 |
| WorkBuddy | 已有被动历史与正文修复；共享写入仍为实验，真实原生写入验收未闭环 |
| Claude Code | 内置 CLI stream-json 适配器，原会话恢复和本机持久历史；具体功能与验收见[接入契约](claude-integration.md)、支持矩阵 |
| Claude Desktop Code | 独立 Agent 身份、本地 Code 历史与原桌面 LocalSessions 控制桥；需显式连接入口，普通聊天/Cowork/云端不作为本地 Code 接管 |
| Cursor | 有插件扩展边界，未内置生产适配器 |
| 会话 CRUD、搜索、归档、JSON 导出 | 已实现；搜索标题与工作目录 |
| 工作目录与会话分组 | 已实现；从真实会话 cwd 去重分组，支持填写路径新建、折叠、展开及搜索；无会话目录不显示 |
| 本机 Codex 会话发现 | 已实现；分页读取当前用户的工作区内会话，含归档、历史查看及原会话直接续聊/补充/停止/审批 |
| 流式聊天、Markdown、推理、工具输出 | 已实现 |
| 用户消息复制、长消息折叠与日期分隔 | 已实现；普通消息按视觉行测量，严格超过 10,240 UTF-16 单元时先切前段渲染；展开、打印与复制使用全文。采用真实时间来源，缺少历史时间不补造 |
| 用户正文与原生输入投影 | 已实现辅助图片上下文筛选、library 提及恢复、完整 app-input schema 校验与普通包装提取；根据首个有效应用消息决定提取次数。最终 display_text 与原输入分离，实时回显仅在同回合原文唯一匹配时更新；其他特化呈现仍有差距 |
| 用户 Markdown 文件链接 | 已实现用户专属 composerLink 扩展与 codex-text-link 源文本规范化，支持带空格路径、转义与格式化标签、标准标题和未完成链接边界；sites 扩展尚未接入 |
| Codex 文档提及发送 | 已实现 YEe 对应转换；新消息、引导及队列在实际投递时序列化来源 URL 与 UTF-8 显示标记，作者草稿另存。历史编辑走独立 Ooe 路径，不调用新发送转换 |
| 用户消息编辑并重新发送 | 已实现受限原生链路；仅空闲、持久化 paginated Codex 会话最新且唯一的用户项，同 thread revert 后保留原输入附件重发；失败草稿与操作阶段可恢复，结果未知先核对、不盲目重发。支持首文本含有效 app/library 元数据的消息，提交后清空旧标记。取消不恢复历史；原生客户端并发修改无 CAS 保证，不能编辑更早回合或有多条用户输入的回合 |
| 普通历史文档编辑器 | 已接入 ProseMirror PZ：16类原子引用、真实段落/选区/撤销、原生引用HTML与纯文本剪贴板、代码块快捷键、长文件名中截；普通文字链接已支持共享动作浮层；显式rich历史与其他引用动作仍有边界 |
| 审批、开放问答、中断 | 已实现；一次/回合/会话及请求原提案规则分开处理，精确决定白名单与并发去重，长详情独立滚动，安全条件下支持 Enter/Escape |
| 原生模型、推理强度、服务速度 | 已实现；真实目录与权限过滤、强度滑杆、快速开关/速度浮层、原线程设置恢复 |
| 主输入框富文本 | 已接入原生式ProseMirror schema、格式快捷键/输入规则、标题、列表、任务、代码缩进和表格；保存实际文本、Markdown与文档，刷新及排队编辑保留格式。补齐字面硬换行、HTML段落间距/空白归一、行内代码选区、媒体/MathML与表格后光标；行内链接已支持打开/改文字/改网址/移除、撤销与复制分离；Google Docs特化、完整HTML及其他引用动作仍有边界 |
| 行内链接编辑 | 已接入原生横向动作条和文字/网址编辑条，支持空网址移除、非法网址保留、焦点/Escape/输入法保护、保留格式/元数据及library身份；主输入与普通历史编辑共用。原provider完整图标/加载注册表、跨host/原生窗口分发及全部选择几何仍待对齐 |
| 输入器会话引用 | 已实现richLink的本地会话直接跳转、Enter/Space、中键及平台修饰键新Web标签页；按当前服务器原thread_id映射，保留原草稿，索引缺失只读刷新，外host/歧义不猜测，迟到响应隔离。普通文字mark保留编辑浮层；跨host自动切换和原生窗口控制仍未实现 |
| 消息正文会话链接 | 已实现user/Agent正文的本地threads跳转、Enter、中键/平台修饰键/Shift新Web标签页、草稿保留与并发隔离；通用正文解析与输入器严格解析分开，非法/空地址显示文字。review/branch/last-turn审阅分屏已接入，支持来源/文件路径、刷新/新页/Back；跨host切换和HTTP内嵌浏览器仍未完成 |
| 主输入历史回溯 | 已实现；空输入末尾↑优先取回队尾，再回溯当前会话输入历史，↑循环/↓前进及清空，改稿退出；保留富文本文档与当前附件，发送失败尝试也记录。浏览器按服务器和会话隔离，每会话20条、最近100会话；不从消息历史猜测，不同步到其他浏览器 |
| 执行中排队与主框编辑 | 已实现；默认直接排队，行内引导/删除，正文可选择的全文预览，三点菜单编辑消息及关闭排队；编辑从队列移至主输入，恢复文字与附件，支持撤销、刷新恢复及原FIFO位置重新提交。关闭排队仅改变后续默认发送方式。空输入的引导快捷键发送队首，空输入末尾按↑取回队尾编辑；保留富文本、附件和等待期间的新草稿。发送中显示进度，未知投递结果禁用编辑/再次引导；反向发送快捷键按运行状态/偏好处理，手机Enter仍换行 |
| 持续目标栏与编辑侧栏 | 已实现真实目标删除、暂停/恢复、完成隐藏及每秒耗时/可用token预算；正文与展开按钮切换目标分屏，支持富文本、保存、还原、更新时间和保存快捷键；长目标使用受控原生文件包装 |
| 自动审批 | 已实现；保持 workspace-write；不会替用户回答语义问题 |
| 多客户端同步及断线补发 | 已实现，SQLite 事件日志 + SSE 游标 |
| 服务重启后恢复原会话 | 已实现，不重放原用户请求，下一次输入 resume |
| 文件浏览、文本编辑、上传图片/附件 | 已实现；非文本文件不提供通用预览 |
| Git 状态与审阅分屏 | 已实现branch共同祖先、未提交/未暂存/已暂存、指定提交与当前轮累计diff，含新文件、重命名/二进制、行号、文件折叠、左右对照、换行和Git空白过滤；冷历史无累计通知时不补造。提交子菜单包含当前分支最近100项、完整说明、时间、选中状态、加载/重试/空态及手机返回；200ms鼠标展开、键盘取消与焦点分流、行锚定、截断标题完整提示和关闭清理已接入。提交临时选择不覆盖常规来源偏好。正文已接入Pierre、Codex深浅色语法主题与词级高亮，语法资源按需缓存；全文件上下文、虚拟化、评论/搜索和完整tooltip/flyout provider仍有差距；写操作经Agent或终端执行 |
| 移动 PTY | 已实现，独立工作目录 shell，含移动快捷键 |
| PWA、主题切换、响应式布局 | 已实现 |

本轮语音输入、朗读与语音通话/转写继续延后；已实现的文本编辑链路不代表原版富文本编辑器、所有消息分支或会话部分的 1:1 验收已经完成。具体参考差异与项目验证分别见参考契约和验收记录。

以上未实现项不是界面中的假开关。功能迭代可以独立添加插件适配、出站 Runner 或原生推送，不需要更换当前事件日志和客户端聊天投影。

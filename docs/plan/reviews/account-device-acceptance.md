- 每项结果绑定实际源码提交、执行环境和日期。上游报告、单元夹具、浏览器模拟、真实云服务和物理设备分开记录。
- 测试只使用隔离目录、测试账号和临时会话；不向既有原生 Agent 会话发送提示，不读取用户业务正文，不停止未归本任务持有的进程。
- 任何核心门槛未通过，都不能将整套功能、生产更新或安全性标记完成。
- 无业务明文入云不等于零身份/连接元数据。元数据、永久 fence/seed、备份和访问日志边界按实际配置披露。

| Opaque authority at the final writer | [Qualification/Admission](../../../crates/agent-sdk/src/qualified.rs#L26) retain immutable binding and a mandatory caller authority. [Core::admit](../../../crates/agent-sdk/src/qualified.rs#L370) holds the same state mutex used by close/cancel while checking deadline, registration and the callback, then marks admission. [Stdio writer](../../../crates/agent-sdk/src/qualified.rs#L846) and [Unix actor](../../../crates/agent-sdk/src/qualified.rs#L918) call it only after receiving the queued envelope, immediately before their bounded write. No binding retarget or second unqualified queue follows admission. Actual lifecycle/current-peer/occurrence/I02 checks remain the future server authority's responsibility. |
| Queue cancellation and disposition | [Registration drop](../../../crates/agent-sdk/src/qualified.rs#L483) removes the actual pending entry synchronously; a canceled queued envelope cannot pass admission. Cancellation ordered after admission is Unknown, including when the first write has produced no bytes yet. [send/call](../../../crates/agent-sdk/src/qualified.rs#L760) share the monotonic deadline across queue/write/reply waits; refusal/expiry before admission is NotAdmitted. Partial write, admitted timeout, generic native error, EOF and close do not become not-sent/native-accepted proof. A LocalWrite is expressly weaker than a native Reply or semantic acceptance. |
| Unix final writer and bridge seam | The actual Unix writer is inside `socket_actor`, not the channel sender. The independently rerun real Unix pressure test retains a 16 MiB frame in flight, revokes the queued binding and proves only one frame reaches its fake host. [LegacyBridge rejection](../../../crates/agent-sdk/src/qualified.rs#L569) occurs before channels/process creation and returns UnsupportedBridge/NotAdmitted. Old bridge consumers remain unqualified; their existing accepted oneshot is not renamed native acceptance. No optional ignored qualifier or raw fallback was introduced. |
| Sticky terminal and success suppression | [Core::close](../../../crates/agent-sdk/src/qualified.rs#L318) sets one sticky terminal state, resolves/drains pending registrations with their actual admission disposition and updates a separate watch. Metadata/event receivers observe terminal without requiring sender destruction or queued receipt draining. [Metadata publication](../../../crates/agent-sdk/src/qualified.rs#L335) fails closed; [reply routing](../../../crates/agent-sdk/src/qualified.rs#L408) checks terminal after Response receipt publication so receipt overflow cannot escape as RPC success. Producer/authority panic paths revoke rather than leave a live writer. A write admitted before close may still be attempted; only observed task quiescence permits treating the old local writer as gone. |
| Count/byte bounds and retained packets | Default metadata is 128 receipts, 2 KiB/item, 256 KiB aggregate; outbound is 16 envelopes, 32 MiB/item, 64 MiB aggregate; incoming is 128 frames, 32 MiB/item, 64 MiB aggregate; pending limit is 128. Limits cannot exceed these maxima. [Budget reservations](../../../crates/agent-sdk/src/qualified.rs#L188) enforce count/item/aggregate together and Packet owns reservation until drop, including held replies after close. [Bounded serializer](../../../crates/agent-sdk/src/qualified.rs#L814) limits encoded output before retention; [enqueue](../../../crates/agent-sdk/src/qualified.rs#L670) moves params instead of cloning arbitrary payloads first. Cancellation may retain an already queued envelope only within these bounds until discard/close. Metadata contains no input/provider object. |
| Input limits before parse | [Stdio reader](../../../crates/agent-sdk/src/qualified.rs#L885) reads at most item-limit+1 before parsing, with an independently capped 8 KiB read buffer; oversized unterminated input need not wait for EOF/newline. Unix config sets both maximum frame and assembled-message size before reception. The real oversized-header test proves rejection without a payload body. These are encoded-wire bounds, not a promise about parsed JSON allocator overhead or I06's unchanged legacy queues. |
| Cleanup and last owner | [Transport drop](../../../crates/agent-sdk/src/qualified.rs#L562) closes admission before asynchronous teardown. [Supervisor](../../../crates/agent-sdk/src/qualified.rs#L951) aborts and joins local tasks and retains owned kill/reap responsibility inside one five-second budget. CleanupUnknown keeps the supervisor/resources rather than claiming quiescence; a later observed Reaped/Detached can replace it. Existing tests prove repeated close, owned reap, last-owner drop without receipt draining, external-host survival and a non-abortable task held beyond the initial budget. An arbitrary blocking authority callback cannot be preempted safely; its short/nonblocking/no-reentry contract remains mandatory. |
| Dormant and staged ownership | Public-to-SDK types need no dormant dead-code suppression. The module does not construct a permissive authority or derive current runtime/native identity from JSON. B/C must supply the real authority, replace all installed raw handles, qualify initial/ongoing producer effects, migrate bridges at the final adapter mutation and integrate durable preparation/creation. Native-positive advice stays denied. N1 event-consumer scheduling and N2 typed I02 worker/manual origin remain their reviewed owners, not a second SDK policy implementation. |

## Nonblocking note and remaining gates

**N1 / P2 / non-blocking: injected-clock seam is not delivered.** The lifecycle A delivery table mentions an injected clock. The SDK actually accepts explicit monotonic deadlines and uses `std::time::Instant` internally, without an injectable Clock interface; its deadline tests use real bounded time. This satisfies the task's explicit monotonic deadline/no-wall-clock requirement, but module PASS must not describe the broader injected-clock seam or five-second native observation freshness as implemented. Before B/C, preserve a clear owner for that test seam and for native freshness; do not create an SDK observation cache merely to add a clock. This note does not establish a current stale-writer safety defect or authorize wider server changes.

Root owns merge and merged regressions. Future source reviews must still verify actual server CommitCell admission/close ordering, initial imports/media/child effects, same-Arc peer replacement, event progress and automatic responses, complete caller migration and I02 preparation/dispatch authority. Legacy RpcProcess and unmigrated bridge users remain outside qualified safety. Five-second native freshness, full typed critical errors, durable restart fences, native ACK/query semantics, actual accounts/platforms and all new capability/Web consumers remain open. A module pass cannot close these dependencies, activate a partial Runtime migration or authorize production restart/release.

# Android 设备状态与连接修复

状态：调查与修复中。用户截图显示同一账号在网页可看到电脑在线并访问；Android 原生客户端已登录并读出同一设备目录，但提示“暂时无法确认设备状态，请刷新重试”“状态暂时未知”，无法访问。

目标：定位 Native/Web 协调配置、授权、设备注册、在线状态及连接路径的差异，让 Android 能正确取得设备在线状态并建立已授权连接。保留未知状态、离线状态和失败的区别，不把查询失败伪装成在线，不跳过账号、公钥及配置绑定。

Mendel 在隔离工作树负责 mobile 账号/协调/连接实现与针对性回归；Hilbert 独立审查。与桌面首次登录故障共享调查结论，避免客户端分别加入掩盖同一问题的兼容逻辑。验证必须执行到实际协调实现边界，不能仅依赖非 Android 的不可用 stub 或浏览器状态投影。

修复合入后由 Android 构建 owner 将精确源码纳入四种独立 ABI APK，并保留随包 UI、签名、身份及 16 KiB 检查。测试不使用真实账号、物理手机或用户原会话；真实账号/设备手测未完成时明确保留边界。

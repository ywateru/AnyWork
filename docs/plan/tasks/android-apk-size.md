# Android APK 体积优化

状态：进行中。用户反馈 v0.1.34 的公开 APK 过大，要求优化安装包。

基线：main `bb75bf7`，v0.1.34 APK 为 204,082,412 bytes。先测量正式包 ZIP 条目、原生 ELF、DEX 和随包界面的实际占用，再选择优化，不把压缩后的下载大小等同于安装占用。

交付约束：保留完整 Rust/Tauri 2 客户端、随包 UI、内嵌登录、原生连接及系统功能；保留四 ABI、applicationId、minSdk、发行证书和 ELF/ZIP 16 KiB 兼容。优先限定 Android 构建的优化，不无意改变桌面 release 配置。旧 tag/附件不可覆盖；新发行遵循精确源码 Checks 和现有完整发行门禁。

作者 Boole 在隔离工作树完成测量、实现及实际 Release 构建；Mendel 独立审查精确提交与包内容。验收需包含具体前后字节数、各 ABI 库占用、签名/身份/随包资产/对齐、R8/lint/JVM 检查，明确测试签名候选与正式发行的区别。无需真实账号、物理设备或 Claude Desktop 真机测试。

交付记录与证据待验收后补充；构建缓存、下载包、签名材料不提交。

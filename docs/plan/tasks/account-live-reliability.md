# 账号远程连接的实际可靠性修正

用户实测报告：同一新账号登录后设备未出现，Native偶发`REMOTE_ENABLE_GRID_CONFIG`、稍后重试成功；已连接工作区频繁显示授权过期；正式站点`/agents/codex-light.png`等图片无法显示。

## 调查与实施边界

1. 只读探测公开Grid配置、图片及实际部署资源，不读取用户新账号的grant、设备目录或业务内容。隔离测试使用既有synthetic用户或本地夹具，不复用用户真实工作区。
2. 区分配置内容不一致与暂时DNS/TLS/HTTP失败。只有幂等配置GET可以有限重试；确实配置不符必须失败关闭，不能跳过issuer/client/resource检查、重复OAuth轮换或开启明文通道。日志与用户错误不得携带令牌、URL查询凭据、响应正文。
3. 当前协议把授权和连接都限制为最多300秒，没有续期，因此正常使用也会离开工作区。修正应保留短期JWT并在原加密通道内重新验证授权，或采用等价的独立审查方案；不得仅延长未验证授权。每次更新仍严格校验同owner、issuer、audience、SPA client、connect、exp/nbf，过期/失败/本机关闭仍中止HTTP与PTY。不得自动重放任何业务写入。浏览器账号切换、退出、取消必须停止续期，令牌继续不进入持久文件或诊断。
4. 静态图片使用与实际Web部署base一致的路径，兼容本机根目录与正式`/app/`；公共直链如需保留应在同一受检静态产物中提供。缺失图片不能靠放宽CSP或转发用户业务内容解决。

## 分工与交付

连接生命周期实现与协调/静态资源实现分开工作树，不同reviewer独立审查。先形成根因与可复现回归，再实施最小修订。相关源码/协议文档、真实临时到期/续期、安全失败和部署路径验证一并交付；发布前精确产物受检。当前用户正在运行的Native/服务/远程连接不擅自停止，实际更新须先检查就绪并保留原数据与通道。新部署使用新的持久operation，不能重放既有已完成发布。

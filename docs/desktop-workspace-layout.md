# 桌面控制台与访问说明

日期：2026-11-10。本文记录此前已交付的两栏改版。用户随后要求启动先介绍、登录后准备服务和活动连接状态；当前启动顺序与新视觉以[桌面启动引导与连接控制台](desktop-onboarding-layout.md)为准。下述裸地址、复制边界与浏览器安全交接要求继续有效；旧首屏顺序不约束新一轮实现。

## 目标与视觉

桌面应用是这台电脑的控制台，工作区在浏览器中使用。首屏先回答“本地在哪里打开”，再回答“手机和远程网页如何进入”，最后解释数据与连接如何流动。保留单屏内的本地与账号入口，不恢复旧线路设置。

采用轻灰画布 `#f7f8fa`、白色内容区 `#ffffff`、深色正文 `#202630`、次要文字 `#697482`、蓝色操作 `#2457d6`、边界 `#dce2e9`。沿用系统字体和随包中文字体；标题 26–28px、正文 14–15px、地址 18–20px，地址用系统等宽字体。所有内容左对齐。让真实访问地址成为本地面板的视觉重点，减少重复边框和说明堆积；状态始终有文字，不单靠颜色。

960×720 和 800×620 的窗口优先保证本地地址、打开按钮、账号和远程状态可见；辅助说明可向下滚动。宽窗口使用两栏，窄窗口按本地、远程、原理排列，390px 不横向溢出。设置和更新沿用同一外壳，字段、说明与动作分组清楚；不改变现有更新确认与服务所有权约束。

## 本地地址与操作

- 地址只能由最近一次 `desktop_snapshot.config.port` 的有效整数端口构造 `http://127.0.0.1:<port>/`。不使用尚未保存的设置草稿，不硬编码 3210，不推测局域网地址，不使用 provider 的公网地址。
- 状态尚未取得或端口无效时明确显示地址暂不可用，禁用复制。服务未就绪时标注地址为已配置/启动后使用，不能显示为已经可访问；复制只在本地服务已授权且运行中开放。
- “复制本地地址”仅复制无凭据的根地址，并报告成功或失败。禁止复制一次性 ticket、长期 bearer 或任何账号凭据；轮询不得清掉操作反馈或覆盖设置草稿。
- “打开工作区”始终调用现有 `desktop_open`，通过一次性交接建立本机浏览器会话。显示的根地址不是免认证入口；明确说明首次使用、切换浏览器或本机会话过期时，应点击该按钮。已授权的同一浏览器可用本地地址再次访问。
- 本地地址仅属于这台电脑，手机访问该地址指向手机自己，因此手机和远程网页使用账号设备入口。无需云账号的本地访问不等于取消本机认证。

## 工作原理与状态说明

说明必须反映现有行为：登录不会自动开启远程；本地服务就绪后才能启用远程；设备在线、远程授权和浏览器登录是不同状态。登录中、失败、重新授权、开启中、关闭中均保留现有取消/重试动作，不因改版改写账号控制逻辑。

会话、文件和终端内容在用户设备上处理，远程通过端到端加密通道连接。本轮不新增云端业务数据库，云端仍会处理账号与必要连接元数据；禁止“云端接触不到任何用户信息”等绝对表述。原理区用少量图标和真实路径关系解释，不展示 JWT、Redis、端口转发等普通用户无需操作的细节。

账号凭据和设备私钥只在内存中。重启需重新登录和开启远程访问；关闭远程不停止本地工作。首次连接与换钥仍需身份核对，不自动接受。

## 验证

构建与 TypeScript 检查、已有桌面账号/更新流程回归、真实生产 UI 的四种尺寸截图检查；新交互覆盖端口随快照变化而非设置草稿、未就绪/缺失状态、复制内容无凭据与失败反馈、打开仍调用现有交接。测试使用合成状态或自有隔离服务，不读取真实业务正文，不操作用户登录和远程授权。客户端本机更新仅替换受检 UI/Native 包，优先保留已运行且字节未变的服务，不重复前一轮服务交接。
